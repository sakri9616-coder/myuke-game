# 02 パネル規約書： 誰が書いても同じ形になるための作法

Astryx の実績が示したこと： コンポーネントの命名・props・組み方の規約が徹底して文書化されていると、**人も AI も、初めて触る部品の振る舞いを予測できる**。みゅけの開発主力はクラウド Claude セッションであり、セッションが変わるたびにパネルの作法が微妙にずれるのが実際の損。ここに現行の実績（styles.css / ui-panel.ts）から逆算した作法を固定する。新規パネル実装・改修はこの文書に従う。

## 1. スコープの規律

- パネルのスタイルは `body:not(.strip)` スコープで完結させる。帯に漏らさない、帯の定義を書き換えない。
- 部品の形・IA・ID・JS の契約は不変が原則（Phase P1 の翻訳方針を継承）。見た目の改修で DOM 構造や保存形式を変えない。

## 2. 色の規律

- 色は必ずトークン経由（`01-tokens.md` §1）。生 hex を新規に書かない。
- 状態色は診断文法の範囲だけ： エラー赤（詰まり・✗）、警告黄（⚠）、成功緑、RP 紫、価格・Lv は金、主ボタンは橙、数値は淡緑。**新しい状態色の発明は禁止。** 必要になったら `01` §1 の表に行を足す提案を先に書く。
- 面の階層は `--ide-bg → --ide-panel → --ide-panel2 → --ide-panel3` の4段まで。それ以上重ねない。

## 3. 形の規律

- 角丸は **3px** を標準とする（現行実測の正本）。ピル型は帯由来の `.res` 等の既存部品だけに残し、パネル新規部品では使わない。
- 線は 1px、`--ide-line`（強い区切り）／`--ide-linesoft`（弱い区切り）。影は原則なし（浮き上がりは面の段差で表す）。
- 猫画像・ポートレートの受けは `--ide-paper`（#FFF5E6）の「写真の差し込み」。パネル色で画像を包まない。

## 4. 密度の規律

- 余白は `01` §3 の梯子（4/6/8/10/14）から選ぶ。梯子にない値は使わない（提案があれば梯子側を直す）。
- 情報の並びは頻度順： 高頻度は大きく・上に、低頻度は畳む／グループ化する（sakuri の IA 鉄則）。「煩雑」は失敗。
- 1画面に主ボタン（橙）は1つ。残りは素のボタンかテキストボタンに落とす。

## 5. 数値の規律（経営の洗練はここに出る）

詳細は `03-management-patterns.md` の「数字の憲法」。要点だけ固定する。

- 数値は等幅（`--mono`）＋右揃え。単位は数値より小さく・薄く（`--ide-sub`）。
- **単独の数字を置かない。** 必ず対照（前回比／目標／全体比／上限）のどれかと対で出す。対照は小さく、差分の色は `--delta-*`。
- 桁区切りと省略（k/M 表記）のルールは既存の `fmt` 系に従い、画面ごとに変えない。

## 6. 部品の解剖学（現行実績の型）

新規部品はこの型から外れない。既存の成功形を正とする。

- **カード**（子会社カード等の型）： 見出し行（左： 名称＋状態バッジ／右： 主要数値）→ 本文（属性はラベル：値の小さな行群）→ 操作行（ボタンは右寄せ、主は1つ）。
- **列（カラム）**： 見出し＋件数 → 合計行（`--total-bg`）→ 本体 → 末尾の追加導線（破線の設立カードの型）。
- **表**： 見出し行は `--ide-sub` の小文字、数値列は右揃え等幅、合計行は面を変えて区切る。階層がある場合は `--indent` 単位で字下げし、親行に子のロールアップ値を出す。
- **バナー**： 時代の需要バナーの型（1行・状態色の左帯＋短文）。画面に1つまで。
- **バッジ**： タブの赤ドット／🆕 の既存文法のみ。新種のバッジは増やさない。

## 7. 文言の規律

- コピーとフォントの可愛さは残す（エンジニア風シックは「堅い器に可愛い中身」）。堅くするのは器（面・線・密度）であって、言葉ではない。
- ビジュアルで説明できることは文字で説明しない（sakuri 鉄則）。凡例は最小限、アイコンと色に語らせる。

## 8. Astryx から「採用しない」と決めたもの

- React / StyleX の導入そのもの（土台が違う）。
- 角丸の大きい、余白の広いプロダクト UI の見た目（正本は VS Code の密度と堅さ）。
- 設計原則「Guidance over enforcement（誘導であって強制でない）」は**逆を取る**。みゅけでは正本（理念書・本書）が上で、規約は強制として扱う。複数のセッションが書く以上、緩い誘導では形が崩れるため。
