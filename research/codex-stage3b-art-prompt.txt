『みゅけ、きょうも開発中』（デスクトップ常駐の育成ゲーム）の環境ドット絵を3点描いてください。どれもプレイヤーがクリックして管理画面を開くための「入口」オブジェクトです。

1. prop_phone（24×24）: 小さなプログラマオフィスの電話機。帯のプロジェクトボードの柱の脇に立つ。スタッフ雇用への入口。
2. prop_megaphone（24×24）: 机の足元の床に置かれた応援メガホン。応援（クリック強化）への入口。
3. prop_toolbox（24×24）: 机の下に置かれた工具箱。設定への入口。

スタイル: フラットな色面、輪郭は濃い茶〜スレート系（純黒は使わない）、グラデーションとアンチエイリアスなし、絵の中に文字は入れない。かわいいけれどプログラマのオフィスの小物として一目で読めること。暖色のアクセントは各アイテム1系統まで。

納品形式: graphics/env-sprites-stage3b.js に window.MIYUKE_ENV_SPRITES_3B として、graphics/env-sprites.js と同じ { palette, sprites: { name: string[] } } 形式（'.' = 透明）で。プレビューPNG（4倍・#808080 背景、コンタクトシート付き）を graphics/env-preview3b/ にも。
