『みゅけ、きょうも開発中』（デスクトップ常駐の育成ゲーム）の環境ドット絵を3点描いてください。

1. prop_ship（48×48）: 作品の出荷地点になる小さな出荷台。木のパレットの台に柱が立ち、「出荷」と書かれた札が付いている。スタッフが荷物を積みに来る場所。
2. prop_snackbox（24×24）: 机の足元に置くおやつ箱。クッキーが2枚立って見える、蓋の開いた木箱。
3. prop_snackbox_shut（24×24）: 同じおやつ箱の、蓋が閉まった姿。2と並べたとき同じ箱だと分かること。

スタイル: フラットな色面、輪郭は濃い茶〜スレート系（純黒は使わない）、グラデーションとアンチエイリアスなし。かわいいけれどプログラマのオフィスの風景として読めること。暖色のアクセントは各アイテム1系統まで。

納品形式: graphics/env-sprites-fix1.js に window.MIYUKE_ENV_SPRITES_FIX1 として、graphics/env-sprites.js と同じ { palette, sprites: { name: string[] } } 形式（'.' = 透明）で。プレビューPNG（4倍・#808080 背景、コンタクトシート付き）を graphics/env-preview-fix1/ にも。
