- **リリースタイトル**: `みゅけ、きょうも開発中 v2.3.5 ― 自動アップデート開始`

> 自動アップデート対応の開始バージョンです。**この版だけは今まで通り手動でインストールしてください**。次回（v2.3.6）以降は、アプリが起動時に新しいバージョンを確認し、帯のチップと設定画面からそのまま更新できるようになります。
> あわせて配布ファイルの名前を myuke 表記に統一しました。セーブデータの場所は変わりません（そのまま引き継がれます）。

## アップロードするファイル（このフォルダの中身、そのままの名前で）

| # | ファイル | 備考 |
|---|---|---|
| 1 | `myuke-setup-2.3.5-x64.exe` | NSIS インストーラ。**Updater 用の更新ファイルも兼ねます**（Tauri v2 の NSIS はインストーラ自体に署名が付くため、v1 のような `.nsis.zip` は存在しません） |
| 2 | `latest.json` | Updater が最初に読みに行くファイル。中の `url` は #1 のダウンロード URL、`signature` は #1 への署名（検証済み） |

※ ビルド時の実ファイル名は `みゅけ、きょうも開発中_2.3.5_x64-setup.exe` で、配布名 `myuke-setup-2.3.5-x64.exe` にリネーム済みです。**アップロード後に名前を変えないでください**（latest.json の URL と一致している必要があります）。中身のバイト列は同一なので署名はそのまま有効です。

## アップロード後の確認 URL

1. `https://github.com/sakri9616-coder/myuke-game/releases/latest/download/latest.json`
   → このフォルダの latest.json と同じ内容（version = 2.3.5）が表示されること
2. `https://github.com/sakri9616-coder/myuke-game/releases/download/v2.3.5/myuke-setup-2.3.5-x64.exe`
   → インストーラがダウンロードできること
3. 動作確認: v2.3.5 をインストールした状態でアプリを起動し直しても「最新です」扱い（チップが出ない）こと。次に v2.3.6 を出すときは、この版が自動で検出・更新できることが最終確認になります

## 注意

- `desktop/.keys/` の秘密鍵・パスワードは**絶対にアップロードしない**（リポジトリにも入れない）。このフォルダには含まれていません。
- 配布 zip（`myuke-desktop-windows.zip`、インストーラ＋ポータブル版＋README）は従来どおり別途配る用です。Release の資産は上の2ファイルで完結します（ポータブル版は自己更新しないため Release には含めていません）。
