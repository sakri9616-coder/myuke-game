# みゅけ スプライトシート（sakuriさん作画用）

お待たせ。全部入りセットです。描き直したら、PNGをそのまま返してくれれば
ゲーム用データに変換して組み込むのは私がやります。

## 中身

- `png/` — スプライト1点ごとのPNG（実寸・透過）。いまの絵が入ってるので、
  上から直すもよし、消してゼロから描くもよし。**ファイル名は変えないで**。
- `png/prop_pc.png` — 新規の空キャンバス 40×32（後述のPC分離用）。
- `sheet-guide.png` — 全点の拡大見本（1pxグリッド＋名前＋寸法つき）。赤枠は「地面」の行。

## ルール（これだけ守って）

1. **キャンバスサイズは変更しない**（みゅけ 48×40／スタッフ 32×24／アヒル 24×20／
   アイコン 16×16／小物は各ファイルの寸法どおり）。
2. **一番下の2行が地面**。足や底面はここに接地させる。
3. 透過（何も描かない部分）＝背景。半透明は使わず、色はベタで。
4. 色は下のパレットに寄せると変換が正確。新しい色を使っても大丈夫
   （一番近い色に寄せて取り込む）。

## 猫とPCの分離（sakuriさんの提案どおり）

- `miyuke_code_a / miyuke_code_b` は **猫だけ** で描いて。PCは入れない。
  a と b は「タイピングの前足だけ」が違う2コマにするとアニメになる
  （他が全部同じなら、足だけ描き分け）。
- PC（モニター＋キーボード）は `prop_pc.png`（40×32）に別で描いて。
  ゲーム側で猫の横に配置する。キーボードを猫側・PC側どちらに
  入れるかはおまかせ（置き方は私が合わせる）。
