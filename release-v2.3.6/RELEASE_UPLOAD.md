## アップロードするファイル（このフォルダの中身、そのままの名前で）

| # | ファイル | 備考 |
|---|---|---|
| 1 | `myuke-setup-2.3.6-x64.exe` | NSIS インストーラ。**Updater 用の更新ファイルも兼ねます**（Tauri v2 の NSIS はインストーラ自体に署名が付くため、v1 のような `.nsis.zip` は存在しません） |
| 2 | `latest.json` | Updater が最初に読みに行くファイル。中の `url` は #1 のダウンロード URL、`signature` は #1 への署名（検証済み） |

※ ビルド時の実ファイル名は `みゅけ、きょうも開発中_2.3.6_x64-setup.exe` で、配布名 `myuke-setup-2.3.6-x64.exe` にリネーム済みです。**アップロード後に名前を変えないでください**（latest.json の URL と一致している必要があります）。中身のバイト列は同一なので署名はそのまま有効です。

## アップロード後の確認 URL

1. `https://github.com/sakri9616-coder/myuke-game/releases/latest/download/latest.json`
   → このフォルダの latest.json と同じ内容（version = 2.3.6）が表示されること
2. `https://github.com/sakri9616-coder/myuke-game/releases/download/v2.3.6/myuke-setup-2.3.6-x64.exe`
   → インストーラがダウンロードできること
3. **動作確認（今回が本番テスト）**: v2.3.5 をインストールした状態でアプリを起動すると、少しして帯に「🆕 v2.3.6」チップと吹き出しが出ること。チップをクリック→ダウンロード→「🔁 再起動で更新」→再起動後にバージョンが v2.3.6 になっていること。これが通れば自動アップデート経路の実機 E2E 完了です

## 注意

- `desktop/.keys/` の秘密鍵・パスワードは**絶対にアップロードしない**（リポジトリにも入れない）。このフォルダには含まれていません。
- 配布 zip（`myuke-desktop-windows.zip`、インストーラ＋ポータブル版＋README）は手動配布用です。Release の資産は上の2ファイルで完結します（ポータブル版は自己更新しないため Release には含めていません）。
