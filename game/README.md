# みゅけ、きょうも開発中（ゲーム本体のソース）

デスクトップに住む小さなプログラマー猫「みゅけ」の、軽くてかわいい放置系ゲームです。
v2 では工場シム（工程ライン・スタッフ雇用と育成・第2ライン）と応援クリックが加わりました。
このフォルダはゲーム本体（TypeScript）のソースです。ゲームはデスクトップ版（`../desktop`、Tauri）
としてだけ配布しています（ブラウザ版は v2.6 系の構成変更で廃止しました）。ビルド方法は末尾の「開発」を参照してください。

## 遊び方

- みゅけは小さいPCでプログラミングをしています。放っておいても少しずつ進みます（基本進捗）。
- **このページでタイピングする**／**カーソルを動かす**と、その量に応じて開発がブーストします。
  ページ下部の「自由タイピング欄」でカタカタするのが一番わかりやすいです。
- プロジェクトが完成すると「リリース」になり、**作品棚**にコレクションが増えていきます。
  作るものは毎回ランダムです。
- **帯のみゅけや帯の上をクリックすると「応援クリック」**で開発が直接進みます。連続クリックでコンボ倍率、
  たまにクリティカル（×10）。クリック強化は「応援」タブで買えます（下記）。
- 100DPごとにコミット演出、たまにバグ（本物の虫）が出てきてみゅけが叩きます。

## 操作

| 操作 | 効果 |
|---|---|
| 帯のみゅけをクリック | 頭・体・お腹で反応が違います（お腹は抗議されがち）。たまに「ひらめき」でアイデア+1 |
| 連打 | しっぽブンブンで怒られます |
| 帯の作品棚をクリック | 管理画面の作品棚タブが開きます |
| 🍪 おやつボタン（プロジェクトタブ） | 集中力+18（少しクールダウンあり） |
| 📣 名前を呼ぶボタン（プロジェクトタブ） | 耳だけピクッとする塩対応が見られます |

## システム

- **集中力**: 開発で少しずつ減り、一人遊び（毛糸・段ボール・毛づくろい・窓の外・しっぽ追い・運動会）や昼寝、おやつで回復します。尽きても失敗にはならず、勝手に休憩するだけです。
- **開発工場ライン**: 企画→実装→テスト→ビルド→出荷 の5工程で作品が流れます（状態は工場タブの信号機図で確認できます）。
  各工程には処理レート（DP/分）と仕掛品バッファがあり、一番遅い工程が**ボトルネック**になって
  全体の速度を決めます（工場タブに「⚠️ ボトルネック: ○○工程」と表示されます）。
  実装でバグが少しずつ溜まり、テスト（QA）の処理が追いつかないとテスト工程が詰まって
  実効速度が下がります（詰まるだけ、没収はなし）。工程ごとの速度はアップグレードとスタッフで伸ばせます。
- **信号機とボトルネックチップ（Sprint 3 → Strip Canon で移行）**: 信号機ランプ（緑=流れている／黄=素材待ち・溜まり気味／赤=バグ詰まり・在庫飽和）と在庫バッファバーは、工場タブの「ライン状況」図に一本化されました。第2ラインと工程を共有するため、判定は両ライン合算です。詰まりがある時はプロジェクトタブに「⚠ ○○が詰まり中 → 対策を見る」チップが出て、クリックすると直し方になるアップグレードや雇用の行までジャンプして光ります。帯側では節目チップが ⚠ 表示に変わって知らせます。
- **「あと○○」ヒント（Sprint 3）**: 購入ボタンは、あと約2分で買える金額まで近づくと「あと ○○🪙」と不足分を表示し、買えるようになった瞬間にそっと光ります（音は管理画面を見ている時だけ）。対象は工程アップグレード・雇用・育成・研究・応援強化・スタジオ拡張・第2ライン建設です。
- **作品棚の見えるコレクション（Sprint 3 → Strip Canon で移行）**: 帯の左端にある作品棚の家具には、完成した作品のミニ箱が実際に並んでいきます（棚の枠数まで）。最新作はリリース直後しばらく金色に光ります。棚をクリックすると作品棚タブ（名前とハイライトの目録）が開きます。
- **帯のアンビエント（Sprint 3）**: デスクトップ帯では、近くのスタッフ同士がたまに立ち止まって小さい吹き出しで雑談します。数十分に1回、まだ雇っていない毛柄の「訪問猫」が帯を横切ることもあります。どちらも眺めるだけの飾りで、資源も音も発生しません。
- **帯でもイベントと進捗が見える（Sprint 4）**: 金のひらめきフィッシュとバグ大量発生は、デスクトップ帯にも現れてクリックで捕まえられます（報酬は管理画面と同じ）。帯の PC モニタの中には現在のプロジェクトの進捗バーが表示され、帯 HUD の左端には「📚 作品数 ／ あと○DPで節目」のチップが出ます。引っ越したてのみゅけは「やる気MAX」で、初リリースまでは生産が大きく加速します（無操作でも約5分で初リリース）。
- **帯の家具化（Strip Canon）**: 部屋シーンは廃止され、みゅけの世界はデスクトップ下部の帯だけになりました。帯には家具で場所を作ります——主デスク（机上のコーヒー・卓上カレンダーつき）、作品棚（背後に柵セグメント）、研究員の小型机（雇った時だけ出現）、第2ライン机（モニタにライン2の進捗表示）、実績で増えるイーゼル看板とトロフィー台。地面は全幅の面ではなく、家具クラスタの下の薄いラグと接地影だけで表します。詰まり表示は「主に第○ライン」とラインまで教えてくれます。
- **スタッフ（スタッフタブ）**: コインで仲間の猫を雇えます。役職は5種——
  プログラマ猫（実装 +2.2 DP/分）、テスター（テスト速度とQA）、運搬係（出荷速度 +5 DP/分）、
  研究員（研究P +0.25/分）、お世話係（集中力の減りを軽減＋たまに差し入れ）。
  雇用費は同じ役職を雇うごとに約1.35倍。雇った猫は**育成**でレベルアップでき、
  1レベルごとに効率+25%（最大Lv10）。毛柄は三毛・茶トラ・黒・白・サバトラ・ハチワレの6種です。
  同時に雇える人数は**スタジオ**の広さで決まり、最初は3人まで。
  コインでスタジオを拡張すると上限が 5→7→9→12人 と増えます。
- **第2ライン**: 研究「並行開発ライン」（研究P 5）→ 工場タブで 1,500🪙 で建設すると、
  2つ目のプロジェクトを並行開発できます。テスト・ビルド・出荷の工程は第1ラインと共用なので、
  そちらがボトルネックだと両方詰まります。報酬は通常の70%。
  **特化ジャンル**を設定すると、そのジャンルの作品だけを狙って作ります（依頼消化に便利）。
- **資源**: にゃんコイン（リリース報酬）、アイデア（一人遊び・なで・考え中で貯まる）、バグ在庫、パッケージ、研究ポイント、星屑。
- **アップグレード（工場タブ）**: キーボード／IDE／モニター／椅子、ラバーダック検査員、自動テスト機、CIマシン、自働梱包機、そして同僚の**子ねこボット**（自動生産）。価格は買うごとに約1.15倍、各トラックにレベル上限があります。
- **研究（研究タブ）**: リリースで得る研究ポイントで、新ジャンル（ゲーム／AIツール／ロボット）、新しい一人遊び、小物、ヘルパー研修を解放。ティア1を終えると**ティア2研究**（ジャンル深化・第2ライン高速化・集中の極意・宝探し・ボットAI学習など7件）が開きます。さらに反復研究「効率化レポート」（生産 +2%/Lv、価格は少しずつ上昇）があるので、研究ポイントが余ることはありません。研究員はティア1完了後、研究メモをアイデアに変える「第二の仕事」を始めます。
- **作品名とハイライト（Sprint 4）**: 作品名は接頭辞×対象×ジャンル×版表記（2.0／DX／完全版／にゃん仕様…）の組合せで500通り以上、しばらく同じ名前は出ません。完成した作品には、開発の実データから「バグゼロの奇跡の一作」「バグ○匹と格闘した力作」のようなハイライト1行が作品棚に刻まれます。
- **依頼ボード**: 他の猫からの注文。期限もペナルティもなし。ジャンルが一致する作品をリリースするとコイン+60%・研究P+1。
- **実績スタンプ**: 初バグ、100コミット、カーソル10km、10作品リリース、夜ふかし開発など。
- **応援クリック（応援タブ）**: 帯クリック1回で威力ぶんのDPが届きます（基本0.25DP）。80%は工程を待たずその場で進捗バーに、残りは実装工程に入ります。
  2.5秒以内の連続クリックでコンボ倍率が +0.08/回 ずつ上がり（基本上限 ×2.5）、
  クリティカルは基本5%で ×10。強化は6種——肉球トレーニング／高級グローブ（威力アップ）、
  応援うちわ（コンボ上限アップ）、応援団の旗（クリティカル率アップ）、
  ひらめき連動／研究メモ連動（クリックでアイデア・研究Pも少し貯まる）。価格は買うごとに約1.30倍。
  たまに現れるクリックイベント:
  - **金のひらめきフィッシュ**: 金色の魚が帯を泳ぎます（約10秒）。クリックで捕まえると研究P+2 と +50🪙（星屑ボーナス連動）。
  - **バグ大量発生**: バグが6匹うろうろします（約20秒）。クリックで叩くと1匹6🪙、全部叩くとボーナス+20🪙。逃がしてもペナルティはありません。
- **プレステージ（引っ越し）**: 工場タブから実行。コイン・アップグレード・研究・スタッフ・クリック強化・スタジオ・第2ラインをリセットする代わりに永続通貨「星屑」（1個=全DP/コイン+4%）を得ます。作品棚・日報・実績は引き継がれます。実行前に、得られる星屑・生産倍率の変化（現在→引っ越し後）・リセットされる物と引き継がれる物の一覧がプレビュー表示されます。
- **星屑ショップ（Sprint 3）**: 工場タブで星屑を使って永続特典（各1回のみ）を買えます——棚の星飾り（2⭐・帯の作品棚の天板に飾り）、初期資金（3⭐・引っ越し直後300🪙）、夢の続き（4⭐・夢のお土産+1）、集中ブースト（5⭐・応援クリック威力+10%）、研究ノート（6⭐・研究1件引き継ぎ）、ベテラン制度（8⭐・最古参スタッフ1人引き継ぎ）。生産倍率は「通算で獲得した星屑」で決まるので、星屑を使っても倍率が下がることはありません。
- **終盤の使い道（Sprint 4）**: スタッフタブの「🎁 ご褒美」で、高級おやつ（集中力+30・30分 生産+15%）と高級おもちゃ（集中力+10・30分 クリック効率+10%）を贈れます。価格は稼ぐほど上がるので、終盤でもコインの行き先が残ります。星屑ショップにはレベル制の特典（星のチャーム=生産+2%/Lv／幸運のヒレ=フィッシュ間隔−8%/Lv、最大Lv5）も増えました。育成コストは少し緩やかになり、「全員+1Lv」の一括育成もできます。
- **セーブの持ち運び（Sprint 4）**: 設定タブからセーブデータを JSON で書き出し／読み込みできます。別の PC へ進捗を引っ越せます（形式が違うファイルは弾きます）。
- **自動アップデート（デスクトップ版 v2.3.5〜）**: デスクトップ版は起動時に GitHub の配布ページへ新しいバージョンを確認し、あれば帯のチップと設定タブからアプリ内で更新できます（署名検証つき）。v2.3.5 が最後の手動インストールで、以後は zip の入れ直しは不要です。
- **点滅を減らす**: 設定タブで ON にすると、帯の点滅（企画中・雇える・ゲージ満タンなどの合図）が点けっぱなしになります。OS の「視差効果を減らす」が ON のときも自動で控えます。
- **時刻連動**: 深夜（0〜5時）のコミットは実績スタンプ「夜ふかし開発」の対象になります。
- **効果音（Sprint 2）**: Web Audio でその場で合成する小さな効果音（素材ファイルなし）が、応援クリック／コミット／バグ叩き／購入／リリース／金の魚／おやつ で鳴ります。設定タブで ON/OFF と音量を調整でき、セーブに保存されます。未設定の間は管理画面では ON、デスクトップ帯では OFF（作業中に驚かせないため）です。音は最初のクリック／キー入力の後から鳴り始めます。
- **おかえりセレモニー（Sprint 2）**: 続きから開くと、みゅけはまず寝ていて、少しして起きて挨拶します。「前回のあらすじ」カード（前回のリリース数・獲得コイン・一緒にいた時間）も出ます。30分以上あけて戻ると「夢のお土産」でアイデアが +1〜3 もらえます（進捗そのものは離れている間も止まったままです）。

## プライバシーについて（大事な設計原則）

- 記録するのはタイピングの**回数**とカーソルの**移動距離**だけです。**キーの内容は一切読み取りません。**
- 自由タイピング欄の内容も、保存も送信もされません（画面に表示されるだけです）。
- 通信するのは、アップデートの確認と取得のために GitHub へ行くときだけです（v2.3.5〜）。セーブや入力の集計が送られることはありません。
- セーブはこの PC のアプリ用フォルダ（`miyuke-save.json`）に保存されます。WebView の `localStorage` にも同じものを控えとして書き、起動時は新しい方を使います。
- 設定タブから入力カウントの一時停止と、セーブデータの初期化ができます。

## 入力の数え方

- 既定では、みゅけの帯とメニューのウィンドウの中での打鍵・カーソル移動だけを数えます。
  設定タブで「OS全体の入力カウント」を ON にすると他のアプリでの打鍵・カーソル移動も数えます
  （既定は OFF、回数と距離だけを数え、内容は記録しません）。
- ウィンドウ内のカーソル距離は実 px の移動量です。

## バランスについて

数値は `tools/balance-sim.js`（Node製ヘッドレスシミュレーション）で30日分を検証済みです。
カジュアル想定（1日3時間・控えめな入力）で、初リリース約5分（チュートリアル作品120DP＋初回加速）、初雇用1日目、
子ねこボット解放2日目、第2ライン建設は放置プレイで7日目（クリック併用で4日目）、
初プレステージ約2週間が目安です。応援クリックのセッション中は、放置時の約2.9倍の
生産速度になるよう調整しています（放置だけでも詰まらないバランスです）。
Sprint 3 では星屑ショップの最小モデル（初期資金→集中ブーストを貪欲に購入）も sim に入れ、
引っ越し後の回復が初回ランより速いことを確認しています（2日目のリリース数: 初回1〜2作品 → 引っ越し2日後 2〜3作品）。

## グラフィックについて

キャラクターと小物は Canvas 上にドット絵で描画しています。描画エンジンは外部の
スプライトデータ（`MIYUKE_SPRITES` 形式）を差し込める設計で、読み込まれていない場合は
内蔵の手続き描画に自動でフォールバックします。

みゅけの歩行（v2.3.3〜・v2.3.4 で sakuri作画の歩行アニメ統合済み）: みゅけが帯を
歩きます。リリース後は作品を作品棚まで運んで置きに行き（棚の最新作の箱はその瞬間に
現れます）、一人遊びの合間には家具のそばまで散歩に出かけます。歩行アニメーション
`miyuke_walk`（7フレーム）は左向き原画で、右へ歩く時は反転して描かれます。歩行は
見た目だけの演出で、生産や数値には一切影響しません。

## 開発

```sh
cd game
npm ci              # TypeScript と ts-blank-space を取得
npm run typecheck   # 型チェック (tsc --noEmit)
npm run build       # desktop/dist/index.html を生成 (Tauri がこれを読む)
```

- 検証は `tools/verify-all.sh`（型チェック＋ビルド＋スプライト検証＋スモーク＋バランス sim ＋帯の実測・撮影）。
  `tools/miyuke-smoke.js` などの検証ツールは、実行のたびにソースからビルドした HTML を読みます。
- ビルドは型注釈を同じ幅の空白に置き換えて連結するだけなので、生成物の行・桁はソースと一致します。
  `enum` や `namespace` のような実行時コードを生む TypeScript 構文は使わないでください（ビルドが止まります）。

## ファイル

- `src/index.html` — HTML の骨格（`@@STYLES@@` などの差し込み位置を持つ）
- `src/styles.css` — メニューと帯のスタイル
- `src/boot.ts` — 形態（帯／メニュー）とロールの決定。本体より先に走る
- `src/game/*.ts` — ゲーム本体。全ファイルが同じグローバルスコープを共有するスクリプトで、
  `build.mjs` の `GAME_SOURCES` の順に連結される（順序＝実行順）
- `src/types.d.ts` — セーブデータ（`GameState`）などの共有型
- `build.mjs` — ビルドスクリプト。スプライトは `../graphics/sprites.js` をそのまま取り込む
- `README.md` — このファイル
