管理メニューを VS Code のような分割ビューにしました。見た目（タブ・色・ボタン・値札）はこれまでのままです。

- タブを、よく開く順（プロジェクト → 工場 → スタッフ → 応援 → 依頼 → 研究 → 作品棚 → 統計 → 設定）に並べ替えました。
- 左端にアイコンの列を置きました。全部のタブがいつでもここから開けます。めったに開かない統計・設定は下に寄せ、最初は閉じてあります。
- タブの × で閉じられます（ホイールクリックでも閉じます）。閉じたタブはアイコンの列から開き直せます。
- タブをドラッグして別のタブ列に落とすと移動、パネルの上下左右の端に落とすと（青い面が出ます）そこが分割されます。境目をドラッグすると幅を変えられます。分割は4つまでです。
- 広い窓では、最初は左に「プロジェクト・応援・依頼・作品棚」、右に「工場・スタッフ・研究」の2分割で開きます。
- 配置は管理ウィンドウに保存され、次に開いたときも同じ配置に戻ります。設定タブの「メニューの配置 → 元に戻す」で最初の配置に戻せます。セーブデータには混ぜていません。

帯の表示・遊び方・数値は変えていません。
