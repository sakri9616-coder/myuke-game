# v2.29.0 — 全体の見直しと、依頼の「品質★」

## 遊びの変更
- **営業が取ってくる依頼は、作品の品質★を求めるようになりました。** 中小企業・大企業の依頼は★2以上、自治体・グローバル級と大型案件は★3以上で満額のボーナスです（届かないと半額）。これまでの「サイズ以上」の条件は、作品がほとんど M/L になる零細以降ではまったく効いていませんでした。品質★は企画・モジュール・ブランド（バグゼロ出荷）で上がります。
- **大型案件を受けると、次の作品は L の大作で作ります。**
- **ご褒美（高級おやつ・おもちゃ）の値段を「いまの自動収入の約4分ぶん」にしました。** 2社目以降は値段が収入の数日ぶんまで膨らみ、買えなくなっていました。
- **営業は「零細」から雇えます**（社格の予告どおり。すでに雇っている営業はそのままです）。

## 直した不具合
- 新しい会社が、起動して1秒で「零細」に上がっていました（企業価値に一時的な新人ブーストが入っていたため）。
- 納期を過ぎた依頼でも、研究P +1 が付いていました。
- イベントの報酬の目安に、子会社が再投資にまわす分まで入っていました。

- 右の社格タブの文字が枠線に触れていたので、枠を少し広げました。
- 別館看板の札が長い作品名で伸び、ビルド台の柱に隠れていました。
- 部長の ⭐ が吊りメモの文字に重なっていました。
