どの収入源を伸ばすかを、プレイヤーが自由に組めるようにしました。

**自由ビルド（経営方針のプリセットを廃止）**
- 会社ごとに経営方針を1つ選ぶ形をやめました。どこに強化を積むかで、その会社の稼ぎ頭（主役）が決まります。
- 収入源ごとに専用の強化を追加しました。
  - 工場タブ: 「直販ルート」（作品そのものの売上 +10%/Lv。作品棚には効きません）
  - 作品棚タブ: 「販促キャンペーン」（棚とシリーズの売上 +10%/Lv）、「棚を広げる」（並ぶ本数 +2・売れ続ける時間 +10%/Lv）
  - 依頼タブ: 「目利き」（依頼達成ボーナス +10%/Lv）
  - 子会社: 「グループ経営」（子会社の売上 +40%/Lv）
- 労働は応援タブの強化で伸ばせます。
- プロジェクトタブに「収入の内訳」を追加しました。この会社でどの収入源がいくら稼いだかと、いまの主役（👑）が分かります。
- すでに経営方針を選んでいた会社では、その会社を売却するまで方針の効果が続きます。

**スタッフタブ**
- 部署ごとの列に並べ直しました。列の上に部署名と Lv.up、その下に所属の猫、いちばん下に雇用ボタンがあります。
- いちばん上は次の社格の予告（あといくらの企業価値で昇格するか）です。

**ほかの変更**
- 作品棚に並ぶのは新しい4本までになり、新作が出ると前の作品の売れ行きが落ち、時間とともにも少しずつ落ちます。そのぶん1本あたりの売上は大きくしました（放置でゆっくり出した作品ほど長く稼ぎます）。
- 子会社の売上を2倍にしました。子会社を売ったときの星屑は、その子会社の売上から決まるようになりました（会社ごと売却するときは、子会社の売上も企業価値に入っています）。
- 強化が増えたぶん、星屑1個ぶんの企業価値を見直しました（秒5クリックで約15分、放置だけで約2時間で星屑20個）。
- 売却の画面の説明を、企業価値の最高値で書くようにしました。

セーブデータはそのまま引き継がれます。
