「自社IPを狙う」を、狙うかどうかを考える仕組みに作り直しました。

**自社IP ねらい**
- IP を狙うと作り込みが必要になり、作品の規模が 1.5 倍になります（作品が半分できる前まで選べます）。
- バグ0で出荷できれば IP になり、すぐに値段の30%、その後 48 時間のロイヤリティで合計 約2.3倍が入ります。
- 出荷のときにバグが残っていると IP にならず、値段が 0.8 倍になります。
- IP は会社の資産なので、売却（EXIT）すると消えます。しばらく売却しない会社で狙うのがおすすめです。
- 狙っている作品は、仕上げが近づくとボードに残りのバグ数が出ます。0 にしてから出荷しましょう。

**企画会議の調整**
- 会議の長さを少し長くしました（作品の実装時間の 2割 → 3割）。そのかわり、会議中に止まった実装のぶんも星屑の元に数えるようにしました。後ろの工程が詰まっている時に開けば得、実装が追いついていない時に開けば損、という差がはっきりします。

セーブデータはそのまま引き継がれます。
