# v2.35.0 まとめ買いの直しと自動雇用の廃止

## まとめ買い（長押し）の不具合を修正
- 上限が近い購入（応援強化など）で、残りが50を切ると長押しメニューが出なくなっていた問題を修正。「+残り全部」のボタンが出るようになりました
- 一括育成の行で、全員分のお金がないと「最大」や長押しまで押せなくなっていた問題を修正。安い順の振り分けは、1歩ぶんのお金があれば使えます
- ドラッグして離すときの判定を広げました（見た目はそのまま）。ボタンの少し外や、ボタン同士の隙間で離しても拾います

## 星屑ショップの表示
- レベル制の特典に「何が上がるか」を表示しました（例: 応援クリックの威力 ×5.43（次 ×6.17））。今までは倍率だけでした

## ボタンの並び
- 購入ボタンと「最大」が横一列に並ぶ規則を復旧しました。狭い部署カードで「最大」が下に落ちていたのを直し、各ボタンが1行を取り切るようにしました
- 雇用の「最大」ボタンを外しました（人数を埋め尽くす買い方をなくすため）

## 自動雇用の廃止
- 部署Lv10の「自動補充」（空きがあると同じ役職を雇う）を廃止しました。スタッフは手動での雇用だけになります

## 解雇を追加
- スタッフを解雇できるようになりました（スタッフタブの各猫の行に「解雇」ボタン）
- 解雇すると、育成に使った費用だけが戻ります（雇用費は戻りません）。確認ダイアログで返却額を表示します
