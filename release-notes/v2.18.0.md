再設計の段階6（周回の上の層）です。売却をくり返すほど次の会社が速く立ち上がり、星屑の使い道が主役の収入源ごとに分かれます。旧セーブとの互換は取っていません。

- 星屑ショップに収入源ごとの「枝」を足しました（労働・本社ライン・作品棚・営業・子会社。上限なし）。その会社でその収入源の強化の列に投資したほど強く効きます。星のチャームは廃止しました。
- 初期資金と星の貯金箱は固定額をやめ、前の会社の自動収入の10分・30分ぶんになりました。
- 子会社に配当率を付けました。配当しない分は子会社が自分の人員と規模に再投資して育ちます。
- 「目利き」で大型案件が届きやすくなります（上限50%）。自社IP 1本ごとに子会社の売上 +10%・依頼達成ボーナス +5% の相乗が付きます。
- EXIT の節目: 1回目で研究の自動選択、3回目で「零細」から創業、5回目で設備の自動購入、8回目で「中小」から創業、12回目で部署の自動 Lv.up。
- 持株化の条件を EXIT 12回と「この時代の通算星屑 100京個」にしました（放置1日3時間で約1週間の目安）。星団は通算星屑の桁3つごとに1個です。見た目だけのオフィスグレードは持株化の回数で自動で開きます。
- チャレンジの目標を見直しました（社格は開始社格から3段上、ブラック企業は企業価値が星屑10個ぶん）。
