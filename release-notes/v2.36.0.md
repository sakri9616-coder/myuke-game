# v2.36.0 まとめ買いが止まる問題・価格表示・配当バー・数字の幅固定

## 「最大」や +50/+100 が途中で止まる問題を修正
- 残高がとても大きい時に、安い強化1回ぶんの支払いが数字の丸めで消えてしまい、「買えなかった」と誤判定してまとめ買いが1回で止まることがありました。買えたかどうかを購入記録でも判定するようにし、止まらずに続くようになりました
- 一括育成の「最大」で、低レベルのスタッフへ安い順に振り分ける動きが途中で止まっていたのも同じ原因です。残高が続く限り、均等にレベルが上がります

## +50/+100 に「買える分だけ」のボタンを追加
- 50回分を全額は払えなくても、一部なら買える時は、その歩数と価格のボタンを長押しメニューに出すようにしました（例: +50 は無理でも「+27」をその価格で買えます）
- 全額払える時は今までどおり +50/+100 がそのまま使えます

## 大きな桁での価格表示の崩れを修正
- 価格が指数表記（1.87e21 など）になる大きな桁で、金の価格タグがボタンからはみ出して「最大」と重なる問題を修正しました
- 価格タグは絶対に縮めたり隠したりせず、ボタンの側が自然な幅を保ち、行の文字側が縮むようにしています。長い価格はタグの字も少しだけ詰めます

## 子会社の配当バーが押した値にならないことがある問題を修正
- 配当率のバーを、表示時点からの「差分」ではなく「押した値そのもの」で設定するようにしました。表示の更新が遅れている時に連打しても、押した位置の値に正確になります

## 数字の表示幅を固定して、桁の変動で画面が揺れないように
- 上の青い帯の資源数字を固定幅の表示にしました。コインや研究Pの桁が増減しても、数字は自分の幅の中で右寄せに変わるだけで、隣の表示は動きません
- 「詰まり」チップは帯の後ろに移動しました（出たり消えたりしても資源の位置は動きません）
- スタッフ行の訓練ボタンと「最大」の幅を全行で統一しました。価格の桁で行ごとにボタンの位置がずれることがなくなります。Lvバッジにも最小幅を持たせました
