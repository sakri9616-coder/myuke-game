帯の絵のドットが、どこでも同じ太さで描かれるようになりました。

- これまでは帯の倍率が半端な値だったため、画面の解像度や拡大率によって、元絵の1ドットが 1px と 2px に不揃いに割り当てられていました。みゅけが伸び縮みする瞬間や、猫が歩くたびに、太く描かれるドットの位置が動いていました。
- 帯は「ドット倍率」（×1、×2…の整数倍）でだけ描くようにしました。絵の1ドットは、いつも同じ数のピクセルで描かれます。
- 設定の「帯の大きさ」は、ドット倍率を選ぶボタン（×1 / ×2 …）になりました。今までの設定から一番近い倍率が自動で選ばれるので、帯の高さが少し変わることがあります（1080p・拡大率100%の標準では、少し低くなります）。
- ×1 のときは、スタッフ猫がみゅけと同じ大きさで描かれます（×2 以上では、今までどおり一回り小さく描かれます）。
