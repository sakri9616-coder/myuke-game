# v2.30.0 — 家具カタログと、届いた家具78点

## 新しい遊び
- **家具を買って、帯に置けるようになりました。** 設定タブ「家具の並び」の下に家具カタログがあります。買った家具は並べ替えモードで好きな場所へ動かせ、小物は机や棚の上にも置けます。
- 通常の家具はコイン、特別な家具は星屑で買います。家具は見た目だけで、効果はありません。
- **買った家具はずっと持っていられます。** 事業売却（EXIT）でも持株化でも消えません。
- 品は最高到達社格や EXIT 回数で増えていきます。品が多いので、カタログは解放の段ごとにまとめて、開いて見られるようにしました。
- 本棚を買うと、その天板が小物の新しい置き場になります。
- 「しまう／出す」で、帯から一時的に外せます（持ち物としては残ります）。

## 新しい絵
- sakuri とみゅーが描いた家具 78点が、カタログに並びます（L字デスク、こたつ、ハンモック、飲料自販機、上場の鐘 など）。
- 帯に出る「金の魚」が泳ぐアニメになりました。

## そのまま
- 帯の家具はクリックに反応しません。何もない所のクリックは、これまでどおりデスクトップへ通ります。
- 既存のセーブはそのまま読み込めます（家具の持ち物を記録する項目を追加しただけです）。
