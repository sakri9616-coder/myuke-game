# v2.28.1 — バグまわりと子会社の緊急修正

## 直した不具合
- **バグが永遠に減らない問題を修正しました。** 生産が大きくなるほどバグの増え方が QA の処理を桁で上回り、バグ在庫が二度と空にならない状態でした（出荷のたびに技術的負債とブランド低下が確定し、自社IP化もできなくなる状態）。バグの発生を「実際に書かれたコードの量」に比例するよう見直し、QA が在庫に応じて捌けるようにしました。すでに溜まっているバグも、遊んでいるうちに減っていきます。
- **子会社設立の「ジャンルを選ぶ」ボタンが反応しない問題を修正しました。**

## 仕様の整理
- **子会社の方針（量産型／精鋭型／送金型）を廃止しました。** 判断だけを迫る仕組みになっていたため、全社一律の扱いに戻しました。時代の需要ボーナスと、会社Lvの節目で選ぶ特性はそのまま残っています。
- **会社売却時の「次期経営方針」の選択を廃止しました。** 新しい会社は常にまっさらな状態から始まります（これまで方針を選んでいた場合、その効果もなくなります）。
