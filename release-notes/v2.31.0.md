# v2.31.0 — まとめ買いと、メニューのアニメーション

## 買い物が速くなりました
- **購入ボタンを長押しすると、+50 / +100 のまとめ買いボタンが浮きます。** 押したままボタンに合わせて離すと、その回数ぶん買えます。合計価格はボタンに出ます。元ボタンの上で離せば通常の1回買い、外で離せばキャンセルです。
- 一括育成の +50 / +100 / 最大は、安い順にレベルを配るようになりました（1匹だけ高くて一括が止まっていたのが解消）。
- 雇用・育成・部署・工程アップグレード・研究・ご褒美・子会社・星屑特典・クリック強化で使えます。「最大」ボタンは今までどおり隣にあります。

## 動きがつきました
- 買うと「+1」の文字が浮いて、ボタンがポンッと跳ねます。
- タブの切り替えとパネルの表示に、短いフェードとスライドがつきました。
- アニメーションの時間配分を全体で統一しました。OS の「視差効果を減らす」設定では全部止まります。

## そのまま
- 既存のセーブはそのまま読み込めます。
