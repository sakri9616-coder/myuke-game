押して応援する手応えを強くしました。

**応援の熱**
- 1秒に1回以上の応援を続けると、1分ごとに「応援の熱」が1段上がり、応援が 1.1 倍ずつ強くなります（最大10段）。
- 10秒までの手休めでは熱は下がりません。それより長く離すと少しずつ冷めます。

**魚の種類**
- 金のひらめきフィッシュのほかに、捕まえると15秒間 応援 ×5 になる「応援フィッシュ」と、60秒間 生産 ×3 になる「大漁フィッシュ」が出るようになりました。
- いまは見た目が同じで、現れた時の台詞と捕まえた時の文字で種類が分かります（色違いの絵は準備中です）。

**応援係**
- 社格「中小」から、みゅけの横で応援してくれる「応援係」を雇えます。あなたの応援とは別枠で、必ず上乗せになります。

**ほかの変更**
- 応援P は押した回数ぶん貯まるようになりました（秒5回までの上限をなくしました）。
- 連打した時の「+DP」の文字をまとめて出すようにして、帯が文字で埋まらないようにしました。
- キーボードやマウスの実作業の効果が、会社の自動生産に合わせて伸びるようになりました。
- 応援が強くなったぶん、売却で星屑1個になる開発量を 8,000 → 20,000 DP にしました（秒5回の応援で星屑20個まで約16分）。
